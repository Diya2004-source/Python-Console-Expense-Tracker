# Python-Console-Expense-Tracker
# 💰 Expense Tracker (Python + SQLite)

A simple **console-based Expense Tracker** built using **Python and SQLite3**.  
It helps you record, manage, and analyze your daily expenses efficiently.

---

## 🚀 Features

- ➕ Add new expenses with date, category, amount, and note  
- 📋 View all expenses  
- 📆 Monthly expense summary  
- 📈 Category-wise expense analysis  
- 🗄️ Data stored locally using SQLite (no setup required)

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Database:** SQLite3  
- **Modules Used:** `datetime`, `sqlite3`, `os`
